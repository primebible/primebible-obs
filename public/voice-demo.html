📖 Detected Verses

Speak a verse reference to see it here.
Try saying: "John 3:16" or "Romans chapter 8 verse 28"
⚠️ Browser Compatibility Issue
Speech recognition works best in Chrome, Edge, or Safari.
Firefox does not currently support the Web Speech API.

ℹ️ How It Works

  • Click "Start Listening" to activate voice recognition
  • Speak a Bible reference in natural language
  • The system will parse and display the reference
  • Works with abbreviations: "Rom 8:28" or full names: "Romans chapter 8 verse 28"
  • Supports verse ranges: "John 3:16 to 18" or "Psalm 23 verses 1 through 6"

🔗 Integration

  • Add voice-control.js to your project (it bundles the detector and UI — don't also include voice-control-ui.js, which declares the same class)
  • Connect to your Bible API to fetch actual verse text
  • Works with WebSocket for real-time overlay updates
  • Compatible with OBS Browser Source (Chromium-based)
